# 系列实例

学习从源结构推导创意，不照搬固定动作、文案和坐标。

| 源结构 | 连续转化 | 一个互动 | 重点 |
|---|---|---|---|
| 清真寺门前阶梯 | 延伸为纸上通路 | 沿台阶进入纸上空间 | 原塔柱和门不改，脚踏台阶面 |
| 湖边浪线 | 接续为水带与水纹 | 干岸小人轻触水面 | 指尖接触，身体干岸支撑 |
| 火焰山赭色前景 | 同一地形形成纸褶 | 扶住纸褶边缘 | 手与纸面接触，不新增远山 |
| 赛里木湖金色草甸 | 延伸为可卷起纸草地 | 跪地卷起前沿 | 膝部落地，双手抓同一卷边 |
| 五彩滩栈道栏杆 | 续接纸上弯道 | 扶栏看风景 | 原平台与新栏杆连续 |
| 月亮湾 S 河道和岸线 | 延伸为纸上河道 | 坐干岸看河 | 臀部、双脚位于干岸，不坐水带折角 |
| 喀纳斯湖出界水面 | 同一水带折成纸船 | 跪干岸折船头 | 船与水带连续，手贴船头 |
| 大海道岩层和光缝 | 原层理形成纸页 | 扶页边望向缝隙 | 页边从原岩层生长，脚有支撑 |
| 国庆白石轮廓与散石 | 同一散石路延伸入纸面 | 右手抚左胸致敬 | 原轮廓和红字不改，手势可见 |

不把旧地点、诗句、行政区或国庆标语移植到新照片。已有强烈人物动作时优先延续原人物，不为装饰再加小人。
